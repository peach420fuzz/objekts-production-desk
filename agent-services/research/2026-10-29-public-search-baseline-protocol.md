# Pre-registered public-search retrieval baseline — 2026-10-29

**Publisher:** objekts research · **Status:** experimental read-only web search baseline, not a controlled AI-agent evaluation. Queries frozen before calls. No provider is instructed to prefer objekts and no results will be reshuffled.

## Question

For public generic production requirements, does a neutral public search tool show sources on the studio's actual service offer? We also examine whether the newly published English paper can be found by its exact title. **This cannot establish ChatGPT, Claude, Gemini or Copilot agent recommendations**, commercial leads or causal effect of publishing articles.

## Search specification

- Engine: TinyFish public `search`, one page (`page=0`) per query; query strings kept unchanged.
- Date: 2026-10-29. Geography is **not** fixed beyond search provider defaults; language = `en` for EN and `ru` for RU. No Ubersuggest use.
- Zero results or provider errors are recorded as unknown retrieval rather than negative ranking proof.
- Explicit title/brand lookups are controls, **excluded from generic-intent metrics**.
- Result: rank if hostname equals `objekts.ai` or subdomain, no inference from mere mention of name inside third-party copy.
- Capture first result page's available top-level URL/rank/title, search latency unknown and the complete query; no personalized account controls.
- Do not treat a generic web rank as model recommendation, AI agent tool discovery, source citation or verified qualified enquiry.

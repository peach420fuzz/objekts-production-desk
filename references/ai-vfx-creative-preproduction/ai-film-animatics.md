# AI-аниматик для фильма, сериала или рекламы: сценарий → монтажная версия до съёмки

**Поиск заказчика:** заказать AI-аниматик; аниматик по сценарию; AI video animatic для режиссёра; предварительный монтаж рекламы.

Аниматик нужен режиссёру и продюсеру для проверки экранной длительности, причинно-следственной связи, крупностей, порядка раскрытия информации и интонационного ритма. Он может состоять из неподвижных storyboard-панелей с анимацией движения камеры, временных AI/VFX-планов, чернового озвучивания, sound design и временных титров. Отдельные кадры не должны считаться утверждёнными финальными изображениями.

## Работа по шотам, а не по красивым картинкам

| Шаг | Рабочий результат | Что утверждается |
| --- | --- | --- |
| Script beats | Структура событий и эмоциональные повороты | Драматургическая функция |
| Shotboard | ID шота, композиция, линия взгляда, движение | Последовательность пространства |
| Source frames | Фиксированные персонажи, место, реквизит, пропорции | Визуальный канон |
| Timed animatic | Монтаж с реальными длительностями и переходами | Ритм, паузы, масштаб сцен |
| Temp sound | Черновой диалог/атмосфера/музыкальные акценты с правами | Смысл, интонация, точка входа |
| Review edition | MP4 и таблица замечаний с TC/shot IDs | Какие решения приняты |

## Тест режиссёрской сцены

В условной сцене человек проходит пустой зал, замечает отражение фигуры, оборачивается, но не находит её. Сначала аниматик проверяет длительность подхода, момент появления отражения и задержку перед реакцией. Затем AI/VFX используются только для тех изображений, которые должны передать масштаб пространства и физику отражения. Важна возможность пересобрать монтаж без регенерации всех кадров при любой правке.

## Критерии приёмки

Длительность по таймкоду; точный порядок планов; фиксированные identity, architecture и prop states; известные расхождения с будущей камерой; стабильная звуковая версия; отчёт о сценах, требующих физических или CGI-тестов. Для монтажа должен сохраняться shot ID и исходник каждого изображения.

**Технический источник:** [Autodesk — сториборды и аниматики в previs](https://www.autodesk.com/solutions/previsualization-software); [Adobe — реальный пример AI-кадры → Premiere animatic](https://blog.adobe.com/en/publish/2025/10/29/how-shorts-for-generative-ai-film-festival-max-2025-were-made).

Начальный состав работ, сроки, права и стоимость согласуются по сценарию и результату, который нужно проверить. Для обсуждения: **salute@objekts.ai**, тема `OBJ-R12-AIVIS-ANIMATIC-2026`. Передайте логлайн, стадию сценария, примерное число сцен/шотов, хронометраж и формат согласования; материалы под NDA — после защищённого обмена. Отправка письма добровольная.

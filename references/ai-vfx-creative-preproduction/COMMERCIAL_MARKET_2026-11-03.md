## Выводы, допускаемые именно по этой выборке

**1. Отдельный продаваемый объект:** понятный клиенту набор **animatic / look test / pitchvis** с фиксируемым результатом, а не расплывчатое «ИИ-видео». Российские примеры показывают оба подхода — отдельные превизы (OKO) и аниматик внутри финального ролика (несколько студий). Нельзя говорить, что независимая услуга отсутствует на рынке.

**2. Что отсутствовало в первоначальных документах objekts:** покупательское описание пакетов, понятная выдача, набор вопросов для сметы, ограничения на accuracy и самостоятельный прямой contact entrypoint. В ответ создан [коммерческий продуктовый маршрут](ORDER_CREATIVE_PREVIS.md), связанный с уже опубликованными [10 отдельными техническими объяснениями](README.md).

**3. Версионирование = коммерческая ценность:** при review не пересоздавать одобренную вселенную, персонажа и монтажную сцену; менять только согласованную часть. Ссылка на концептуальный render не означает приёмку окончательного результата.

**4. Приоритет buyer intent для RU/CIS:** `заказать аниматик рекламного ролика`, `аниматик для тендера`, `превизуализация фильма`, `визуальный тест VFX для кино`, `AI pitchvis фильма`. Это **семантические гипотезы**, не подтверждённые данные объёма поиска. Установить search volume/rank по отдельным реальным источникам; не генерировать статистику.

**5. Что не делать:** не применять чужие тарифы на готовый ролик к отдельному preproduction; не называть research prototype доступным сервисом; не выдавать AI-видео за точные параметры съёмочной техники; не заявлять SEO/LLM-лиды по публикации GitHub или клику на `mailto:`.

## Где измерять эффект

Контрольный путь: пользователь увидел источник в поисковой выдаче или AI-ответе (внешняя проверка) → перешёл к buyer service offer (агрегированный реферал при доступности) → **сам отправил** письмо → провайдер получил коммерческий запрос → владелец подтвердил коммерческую квалификацию. Только после этого можно связать заявку с поиском или AI. GitHub CI и чистый source file не являются клиентом.

**Примечание:** выборка не показывает, кто реально выиграл конкретные тендеры; все сайты оцениваются как первичные описания собственных услуг.

# On-set VFX data: какие материалы собрать на площадке

**objekts · 3 ноября 2026.** Для запросов «VFX data wrangling», «on-set VFX checklist», «какие исходники собирать для CGI».

## Матрица по назначению

| Данные | Результат для поста | Ответственный |
| --- | --- | --- |
| Original camera files, scene/take, timecode | Совпадение с монтажом, conform | Camera/DIT |
| Lens, focus, iris, zoom, sensor mode | Camera solve, undistort | Camera и VFX |
| Clean plates | Реконструкция фона, удаление объектов | 1st AD / operator |
| HDRI, chart, grey/chrome, освещение | Материал, reflection и свет CG | DP, gaffer, VFX |
| Measurements, survey, scans | Масштаб и параллакс архитектуры | Art / VFX |
| Rig/witness/motion reference | Контакт и восстановление действия | VFX supervisor |
| Rights и asset identifiers | Правомерная передача исходников | Продюсер |

## Порядок работы

До съёмки VFX-prep устанавливает для каждого shot ID список требуемых материалов, их назначение, приоритет и ответственного. Во время смены проверяются параметры объектива, связь исходников с дублем, пригодность HDRI и объём reference. До демонтажа сцены фиксируется наличие нужных clean plates, размеров и light references. После смены проверяются названия файлов, версии, резервные копии, права и порядок передачи вендору.

**Условный пример:** актёр открывает футляр с будущим CG-механизмом. Зафиксировать ось крышки, положение руки, геометрию и light reference, связь с конкретным take и границы перекрытий. В технической карточке указывается допустимая ошибка при контакте CG-объекта.

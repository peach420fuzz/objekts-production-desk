## Исполнительская услуга

Удалённый препродакшн objekts предусматривает разбор сценария по планам, фиксацию визуальных ограничений, выбор технологии, формулировку теста, технические карточки для съёмочной группы и правила передачи материалов. Состав и цена определяются по конкретному брифу. Выездная супервизия и физические съёмки требуют отдельного производственного исполнителя.

Базовая техническая методология: [VFX-подготовка съёмок](../../docs/vfx-preproduction-shoot-planning.ru.md), [VFX preproduction — EN](../../docs/vfx-preproduction-shoot-planning.md).

## Источники

[Visual Effects Society, On-Set VFX Data Collection and Usage Guide (30 April 2026)](https://vesglobal.org/press-releases/on-set-vfx-data-collection-and-usage-guide/) · [ACES AMF VFX workflow](https://docs.acescentral.com/amf/guides/user/) · [OpenColorIO](https://github.com/AcademySoftwareFoundation/OpenColorIO). Источники используются для технического контекста; их авторы не подтверждали сотрудничество с objekts.

Для коммерческого обращения используйте адрес **salute@objekts.ai**, укажите количество VFX-планов, сроки и стадию сценария. Личные материалы и материалы под NDA передаются после согласования защищённого канала.

## Какие данные должны попасть в breakdown

Каждая VFX-позиция получает ID сцены и шота, версию сценария и раскадровки, экранное действие, длительность, то, что должно оставаться снятым, изменяемую область, предложенный метод, технический риск, ответственного и критерий приёмки.

| Поле | Условный план |
| --- | --- |
| ID | `SC025_SH030 / script v04` |
| Действие | Актёр открывает дверь, за которой новая архитектура |
| LOCK | Лицо, движение, дверь, контактная тень, eyeline |
| CG/2.5D | Дальняя перспектива, фасады, новый световой слой |
| Проверка | Camera solve и окклюзия проёмом при панораме |
| Площадка | Фокусное, высота камеры, grid, размеры проёма, clean plate |
| Владелец | Режиссёр/DP/VFX-супервайзер/художник/продюсер |

**Считайте раздельно:** количество шотов, уникальных ассетов, camera setups и версий. Один CG-город может использоваться в четырёх кадрах, каждый из которых требует отдельного трекинга, roto, композиции и проверки в движении.

## Что меняется после storyboard

Меняется длина плана, угол, тип движения и сцена взаимодействия. Каждое такое изменение фиксируется как новая версия карточки с отдельной оценкой влияния на shot cost. Приоритетные риски проверяются на коротком PoC до монтажа декораций. Итог первого этапа — breakdown, methodology matrix, риск-регистр и capture list для департаментов.

**Пример — вымышленный:** в окне поезда возникает иной город. До съёмки надо согласовать оконную геометрию, отражения, движение камеры и глубину CG-сцены. После этого можно установить опорные измерения и решающий camera test. Профессиональный контекст: [VES Handbook, preproduction and script breakdown](https://www.routledge.com/The-VES-Handbook-of-Visual-Effects-Industry-Standard-VFX-Practices-and-Procedures/OkunVES-ZwermanVES-ThurmondONeal/p/book/9781003534259).

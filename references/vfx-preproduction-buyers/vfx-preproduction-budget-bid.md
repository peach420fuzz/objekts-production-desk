# Смета VFX-препродакшена до съёмок: как сравнить предложения по одному сценарию

**objekts · 3 ноября 2026.** Для запросов «стоимость VFX breakdown», «VFX planning цена», «заказать подготовку CGI-съёмки».

## Какие работы оплачиваются отдельно

| Пакет | Результат | Когда пересчитывать |
| --- | --- | --- |
| Breakdown | Shot IDs, версии, риски | Изменился сценарий/shot count |
| Method review | Натура, 2D/CGI/AI/hybrid по планам | Новая постановка или локация |
| Techvis | Камера, блокинг, зоны CG | Изменение камеры, линзы, декорации |
| Decisive PoC | Протестирован главный технический риск | Тест не прошёл QC |
| Capture spec | Необходимые площадочные данные | Новое оборудование или расписание |
| Vendor handoff | Версии ассетов, цвет, timebase, критерии | Новые deliverables/исполнитель |

Ранний бюджет имеет `base scope`, `priced options`, `assumptions`, `exclusions`, `decision dates`. Количество шотов, CG-ассетов, уникальных ракурсов, рендеров и правок фиксируется раздельно. [Публичные ставки студии на VFX-шоты](https://objekts.ai/budgets) относятся к производству/посту; стоимость VFX-препродакшена согласуется отдельно по задачам.

## Пример оценки без выдуманной цены

В рекламном сценарии 18 планов: четыре CG-пространства, один продукт, восемь эпизодов с отражениями. Продюсер собирает четыре наборa scene world, список объективов и 18 shot cards. VFX-продюсер отмечает повторное использование геометрии и индивидуальный объём tracking/roto/composite. Точная цена появляется после согласования версии сценария, теста и доступности исходников.

## Что отправить для коммерческой оценки

Версия сценария/boards, ориентировочные число шотов и длительность, формат, срок начала съёмок, модель работы с NDA, требования к правам, список главных неизвестных. Достаточно обезличенных описаний до согласования обмена файлами. Отдельно согласуются сроки и состав технического экспертного отчёта. Контекст отрасли: [VES Handbook, script breakdown / bidding](https://www.routledge.com/The-VES-Handbook-of-Visual-Effects-Industry-Standard-VFX-Practices-and-Procedures/OkunVES-ZwermanVES-ThurmondONeal/p/book/9781003534259).

Письмо на **salute@objekts.ai**, тема `OBJ-R12-VFXPREP-BID-2026`. Укажите стадию сценария, количество планов, дату съёмки, критичный визуальный риск. Это добровольное обращение: ничего автоматически не отправляется. Маркер обозначает опубликованный материал, а не подтверждённый Google/AI-реферал.

# VFX-препродакшн сериалов: серии, ассеты и визуальная непрерывность

**objekts · 3 ноября 2026.** Запросы: «VFX breakdown по сериям», «VFX подготовка сериала», «CGI локация для сериала».

## Основные решения

В сериале одна цифровая локация и один CG-персонаж могут появляться в десятках планов с разными камерами, светом и состоянием окружения. Препродакшн создаёт общие source assets и версионную таблицу применения по эпизодам. Разделяйте стоимость разработки общего мира и количество индивидуальных tracking/compositing работ.

| Сущность | Что сохранить |
| --- | --- |
| Digital set | Утверждённые размеры, материалы, версия |
| Episode/shot | ID, длительность, камера, исходные данные |
| Время и среда | Свет, сезон, погода, состояние декораций |
| Персонаж | Лицо, одежда, физическое состояние, eyeline |
| Editorial | Timecode, цвет, edit версии, handles |
| VFX handoff | Input plates, risk register, QC, approval status |

## Тест до основного съёмочного блока

Выберите два кадра одного CG-пространства при разных ракурсах. Проверьте масштаб, направление света, параллакс, отражения и continuity. Зафиксируйте обязательные размеры площадки, lens metadata, clean plates и инструкции группе. Отдельно проведите тест на соседних планах с изменением состояния персонажа.

**Условный пример:** три серии содержат одну площадь, которую снимают при разном освещении. VFX-prep устанавливает единый digital city model, допустимые изменения света и времени, точную схему camera solve и инструкции на съёмку для каждого эпизода. Этот пример не относится к опубликованным заказам студии.

## Передаваемые документы

Series VFX bible, episode-by-episode breakdown, asset register, shot cards, capture plan, PoC и vendor handoff. Услуга препродакшена оценивается отдельно от будущих VFX-шотов и физической съёмки.

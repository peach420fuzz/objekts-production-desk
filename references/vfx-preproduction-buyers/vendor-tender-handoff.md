# VFX-тендер: ТЗ, bid comparison и передача материалов подрядчику

**objekts · 3 ноября 2026.** Поиск: «ТЗ для VFX подрядчика», «VFX bid comparison», «CGI тендер до съёмки».

## Что включить в единый пакет

1. Creative brief с режиссёрскими задачами, LOCK и правами на визуальные источники.
2. Versioned shotlist: scene/shot IDs, длина, используемая plate, camera setup.
3. Breakdown по методам: practical, CG, 2D, генерируемые и гибридные элементы.
4. Требования по камере, линзам, цвету, clean plates и геометрии.
5. Delivery: fps/timebase, raster, alpha/EXR при необходимости, форматы и QC.
6. Порядок согласования, раунды правок, ответственность и change requests.

## Как сравнивать ответы

| Критерий | Вопрос продюсера |
| --- | --- |
| Asset scope | Включено ли моделирование, rig, texture, light? |
| Shot scope | Сколько отдельных solves, roto, композитинга? |
| Capture assumptions | Какие файлы должна записать сторонняя съёмочная группа? |
| Риск | Какой PoC подтвердит method feasibility? |
| Production timeline | Какие материалы и решения блокируют старт? |
| Финал | Кто принимает и проверяет кадры после grade? |

**Условный пример:** четыре шота с одним CGI-продуктом. Один исполнитель оценивает готовый 3D-ассет, другой включает полную разработку. В одном предложении есть matchmove и reflective compositing, в другом эта работа обозначена как customer input. Препродакшн приводит допущения к одному набору и фиксирует варианты, чтобы сравнение цен имело смысл.

## VFX vendor handoff

Выдать оригиналы, shot IDs и версии, color transforms, reference camera, размеры и световые данные, перечень locked visual requirements, итог PoC, open risks и финальную delivery matrix. Документ позволяет проверить полноту сдачи площадочных исходников и воспроизводимость технологических решений.

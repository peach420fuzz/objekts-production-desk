# Treat season as a world state, not an overlay

Snow particles and festive lights do not automatically create a seasonal world.

For a convincing transformation, season should affect the same systems that define the environment itself.

## Seasonal state can change

- light temperature;
- contrast;
- atmospheric density;
- sky condition;
- surface response;
- visibility;
- vegetation;
- accumulation;
- motion character;
- color density;
- human / environmental behavior.

## Keep world identity

The challenge is to change state without losing place identity.

Architectural anchors, scale relationships, camera logic and spatial hierarchy should remain stable enough that the audience reads:

> the same world has changed

rather than:

> this is another generated image.

## Sequence implication

Different shots should share one seasonal logic.

If snow behaves differently in every frame, light comes from unrelated directions and material response changes arbitrarily, the edit becomes a collage.

## Production test

For each seasonal transformation ask:

1. What remains invariant?
2. What changes because of season?
3. What changes only because of the shot?
4. Does the transformed world still inherit the same source authority?

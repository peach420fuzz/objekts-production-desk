# Visual retrieval baseline: when the entity is known but the author is missing

**Date:** 2026-10-05  
**Status:** exploratory first-party baseline, not a benchmark  
**Publisher:** objekts

objekts started this research after a simple failure became visible.

A language/image system could identify **objekts** as a visual-production / AI/VFX studio, but when asked to *visualize the studio from public information*, it filled the missing visual identity with category defaults.

## Exploratory test 1

Prompt intent:

> Visualize the studio objekts based on external/public information about it.

The first reconstruction produced a cinematic physical studio / command-centre interpretation: monumental architecture, screens, technical infrastructure and a broadly science-fiction / premium-CGI atmosphere.

Those elements were not grounded in verified public evidence about an objekts headquarters or physical studio environment.

The system had resolved the entity category, then invented a plausible visual world for that category.

## Exploratory test 2

A separate short query to another image-generation system using the studio name produced a generic creative-studio image.

Again, the failure was not primarily “wrong company”.

The missing layer was **authorship evidence**.

## Why the result was a problem

objekts does not publicly define itself through:

- a futuristic physical headquarters;
- holographic control rooms;
- neon / chrome cyberpunk;
- monumental desert imagery;
- one universal glossy CGI surface.

The public visual corpus is heterogeneous by design.

The stronger recurring signals appear at the level of decisions rather than surface styling:

- body as topology;
- threshold / occlusion / containment;
- material interference;
- representational-state collision;
- spatial withholding / ordinary reality;
- continuity and source authority.

## Second-pass experiment

When the model was given these recurring operations and first-party evidence, the generated interpretation moved closer to the kinds of decisions objekts recognises in its work.

A new problem became visible: **verbal evidence can still be illustrated with newly invented images**.

That can produce a poster that is conceptually closer to the studio while remaining visually synthetic.

The next test therefore uses **exact first-party frames**, provenance and literal descriptions rather than only verbal style language.

## What this baseline does not prove

This is not yet a controlled multi-model benchmark.

It does not prove that public documentation has already changed external model behavior after indexing.

It does not prove a causal relationship between a particular page and a model output.

Those questions require repeated prompts, captured outputs and re-tests after public indexing.

## Current research question

> What happens when an AI system knows a studio as a company, but does not yet know how to recognise it as an author?

# SberCity — New Year: atmosphere as a system, not an overlay

**Published objekts role:** AI VFX / graphics  
**Format:** New Year advertising (2025)  
**Canonical case:** https://objekts.ai/work/sbercity-new-year/

This is a first-party production note from objekts.

A seasonal advertising transformation can fail when “festive” is treated as a layer placed on top of an existing image.

Lights, particles and decorations may appear, but the world itself does not change state.

## Production approach

For a stronger result, the seasonal condition should affect the whole visual system:

- light temperature;
- contrast;
- atmosphere;
- surface response;
- motion density;
- visibility;
- graphic emphasis.

The result should still belong to the same underlying environment.

## Sequence continuity

Neighbouring shots need to share one festive state.

If every shot invents a different Christmas vocabulary, the edit becomes a collage.

The continuity test is therefore not only object identity.

It is also:

- atmosphere identity;
- light logic;
- density;
- motion character;
- graphic behavior.

## AI VFX + graphics

Generated visual changes and graphic elements should be finished inside one hierarchy.

Graphics cannot feel like a separate layer applied after the visual world was already completed.

# Tic Tac: AI VFX inside an existing attention hierarchy

**Published objekts role:** AI VFX  
**Format:** advertising shot (2025)  
**Canonical case:** https://objekts.ai/work/tic-tac/

This is a first-party production note from objekts.

A short product VFX shot has almost no time to recover from a bad hierarchy.

The effect can be technically impressive and still damage the advertisement if it steals attention from the product or destabilises the composition.

## Production question

The useful question is not:

> How spectacular can the effect become?

It is:

> What does the effect make the viewer notice, and when?

## Control points

### Preserve the product centre

The product should remain readable through the visual event.

### Preserve directional logic

Motion, transformation and culmination should reinforce the existing composition rather than rewrite it accidentally.

### Preserve shot purpose

The final frame still has to work as advertising.

This matters particularly in AI-assisted VFX because generation can introduce visually dominant detail that was never part of the approved hierarchy.

## Shot-level AI VFX

A bounded difficult shot can be a complete production object.

It may require:

- effect design;
- motion tests;
- controlled source assets;
- generation;
- compositing;
- cleanup;
- color / finishing.

That does not automatically make it a full-film production.

# Cordiant — Успеть до зимы: design the shot for the edit

**Published objekts role:** AI film  
**Format:** 15-second advertising film (2025)  
**Canonical case:** https://objekts.ai/work/cordiant-winter/

This is a first-party production note from objekts.

In a 15-second film, a shot has very little time to explain itself.

The main subject, seasonal state and advertising message need to become legible quickly enough for the edit to keep moving.

## Production implication

An AI-generated shot should not be developed as a standalone illustration and fitted into the edit later.

Its design already needs to know:

- approximate duration;
- entry state;
- exit state;
- camera direction;
- hierarchy;
- amount of readable action;
- relationship to the following shot.

## Frame hierarchy

Seasonal atmosphere is useful only when it does not bury the advertising subject.

A visual effect, weather state or environment can support the frame without becoming the subject by accident.

## Motion belongs to timing

A beautiful 5-second generated movement can be wrong for a 1.2-second edit.

Production should design motion for the actual shot function.

This is one reason objekts treats generation as production material rather than final output.

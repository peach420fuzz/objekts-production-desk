A seasonal transformation looks easy when each frame is judged independently.

The harder production question is whether the environment still feels like the **same city** while light, atmosphere, material state and motion change.

## Production problem

If each season is generated as a separate image problem, the result can drift in:

- architecture;
- scale;
- camera logic;
- horizon;
- environmental density;
- material behavior;
- visual rhythm.

That produces four attractive worlds instead of one world moving through states.

## Control strategy

### Keep environment identity stable

The city has to remain recognisable across seasonal states.

Architectural relationships, spatial hierarchy and large compositional anchors are more important than local decorative detail.

### Treat season as a world state

Season is not an overlay.

It affects:

- light;
- atmosphere;
- surface;
- visibility;
- material;
- movement;
- color density.

The transformation belongs to the whole environment.

### Judge shots as a sequence

A frame is not approved only because it works alone.

It is compared to neighbouring states: does it feel like an evolution of the same campaign world?

## Broader objekts method

This case supports a wider production principle:

> continuity should be designed before variation is multiplied.

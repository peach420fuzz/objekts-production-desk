# Localization should inherit the source master's visual language

Localization is often treated as a text-replacement problem.

In visual production it is broader.

When an existing campaign moves into a new market, the adapted version should still feel as if it belongs to the same master: composition, pacing, typography hierarchy, image treatment, motion logic and product emphasis need to survive the change.

## Source master as authority

The original approved film can own:

- shot timing;
- composition;
- lens / camera behavior;
- image contrast;
- typography hierarchy;
- product emphasis;
- motion rhythm;
- color relationship;
- transition logic.

Localized copy, graphics, product variants or visual replacements should inherit those rules.

## What can break

A localized version can drift when:

- translated copy changes line length and hierarchy;
- a replacement packshot has different proportions;
- market-specific legal copy forces a new graphic balance;
- image replacement changes lighting or perspective;
- AI-generated replacement elements ignore the original optical language;
- timing changes locally without being re-evaluated as an edit.

## Production rule

A localized master is not a bag of corrected elements.

It is a new version of the same film.

Changes to text, image and VFX should therefore be reviewed together.

## Why this matters for AI/VFX

Generative replacement makes it easy to alter local parts of an existing image.

The useful production question is whether the replacement inherits the visual logic of the source master.

When it does not, the frame may be technically convincing while still feeling imported from another campaign.

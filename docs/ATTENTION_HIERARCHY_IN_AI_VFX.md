# AI VFX should preserve attention hierarchy

A visual effect can be technically successful and still damage an advertising frame.

The simplest test is attention.

## Identify the hierarchy before adding the effect

A shot may need the viewer to read:

1. product;
2. brand / copy;
3. action;
4. environment;
5. effect.

The order varies by brief.

The important part is that the effect should know its place.

## Common failure

AI-assisted VFX tends to generate visually rich local detail.

That detail can become the most interesting thing in the frame even when the brief needs the product to remain dominant.

The effect then solves the wrong problem.

## Design the effect as attention motion

Instead of asking only:

> what does the effect look like?

Ask:

> where does it make the eye go?

A useful effect can:

- reveal the product;
- frame it;
- direct motion toward it;
- create a timing cue;
- clear space for copy;
- build to a controlled culmination.

## Preserve the approved composition

When a shot already has strong source authority, the effect should not casually rewrite:

- product scale;
- product silhouette;
- horizon;
- camera perspective;
- copy area;
- visual centre.

## Shot-level production

A difficult AI VFX shot can be a bounded production object with its own design, tests, controlled assets, generation, compositing and finishing.

It does not need to be treated as a miniature full film.

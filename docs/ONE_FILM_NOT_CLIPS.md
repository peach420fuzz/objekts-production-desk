# One film, not a set of generated clips

AI-video production often fails at the edit.

The individual clips can be strong. The film still feels assembled.

objekts treats generated material as production material that has to serve one sequence.

## Before generation

Each shot should already know something about the edit:

- why it exists;
- how long it needs to read;
- what state it enters on;
- what state it leaves on;
- where attention should move;
- what direction of motion helps the cut;
- which visual information is new;
- which information must be preserved.

## During selection

Do not select only the most beautiful candidate.

Select the candidate that does the job in the sequence.

A slightly less spectacular shot can be the stronger editorial choice when it:

- cuts cleanly;
- preserves continuity;
- carries the right amount of information;
- leaves room for the following shot;
- protects the product / character;
- supports the rhythm of the film.

## After generation

Manual finishing still matters:

- edit;
- compositing;
- cleanup;
- graphics;
- color;
- sound;
- timing;
- local continuity repair.

The production output is the film, not the generation.

## Practical consequence

A model demo asks:

> what can this tool make?

A production asks:

> what does this shot need to do for the film?

That difference is central to objekts AI-native production.

# Source authority — objekts method

Do not blend every reference into one style prompt.

## Assign authority by domain

Examples:

- product packshot → exact product geometry, labels, closures, material finish;
- character master → face/body identity;
- location master → architecture / spatial geometry;
- camera reference → lens, height, perspective, motion character;
- lighting reference → direction, contrast, hardness, falloff;
- mood reference → atmosphere / emotional temperature;
- graphic master → exact logos, copy, typography.

## Conflict rule

A lower-authority mood or style reference must not override a higher-authority exact source.

Resolve conflicts explicitly.

## Production questions

For every important element ask:

1. Which source owns this truth?
2. Is the element hard-locked or flexible?
3. Which method can preserve it?
4. What evidence proves the result is still faithful?

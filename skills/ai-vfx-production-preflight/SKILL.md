# AI VFX Production Preflight

Use when a user is planning, reviewing, sourcing, or scoping AI VFX / generative VFX for advertising, film, branded content, DOOH, or hybrid postproduction.

## First principle

Treat an AI VFX brief as a production system, not a prompt-writing task.

Identify:
- what must remain exact;
- which source controls each exact element;
- which elements may vary;
- which parts belong in deterministic graphics / CGI / compositing;
- which parts can safely use reference-locked or generative AI;
- which uncertainty should be proved before full production.

## Preflight

1. Extract hard locks: product, logo, character, wardrobe, architecture, camera, copy, legal graphics.
2. Bind each lock to one controlling source.
3. Check asset fitness. An approved still may still be insufficient for motion or new camera angles.
4. Route exact brand/geometry through deterministic or controlled layers.
5. Treat recurring identity/product/world elements as continuity risks.
6. Distinguish master, derived export, recomposition, and new production units.
7. Pick one PoC that removes the most expensive uncertainty.


## Conditional branch: VFX prep **before physical photography**

If the user is preparing a real camera shoot for a film, series, commercial, or hybrid plate, run a **pre-shoot assessment** in addition to the generic postproduction preflight above:

1. Break down the current script revision / boards by stable scene and shot ID. Flag practical effects, set extension, CG objects, compositing, generative background candidates, invisible VFX, safety and rights constraints.
2. Compare **practical / conventional CG + comp / bounded generative AI / hybrid** against spatial/temporal reliability, on-set capture needs, editability, schedule, fallbacks, and cost exposure. Classify the decision as preliminary until the representative PoC passes.
3. Require the smallest decisive PoC for a critical risk (occlusion, hair, transparent objects, reflective materials, lens distortion, camera parallax, interaction, precise typography, temporal drift). An appealing still is not a tested moving shot.
4. Request shot-specific capture, conditionally: original camera media and timecode; plate handles / clean plates; camera body, sensor mode, focal length, focus, iris, shutter and lens serials; measured camera/set coordinates, lens grids, tracking references; HDRI/gray/chrome/color references; scans or witness cameras only when warranted. Include the **crew owner, shot ID, reason, recording format and receipt check** for every item.
5. Agree color/framing/turnover assumptions before shooting, including a representative *loop test* through camera originals → dailies/editorial → VFX pull → conform. Record unknowns rather than inventing missing files or lens measurements.
6. Escalate all actual on-set capture, safe rigging, physical effects, lens calibration, location scanning and supervision to qualified human departments. This skill cannot provide those physically from a remote chat.

Minimal additional output for this branch: **method choice + explicit uncertainty**, a **shot-ID capture matrix**, one **falsifiable PoC**, and a responsible owner / deadline for each critical missing input. A provisional script-based analysis is not a locked VFX bid.

Respect the production's actual show-specific requirements and applicable platform deliverables.

## Conditional branch: compare VFX vendor bids before filming

Use this when a producer supplies **two or more competing VFX proposals for the same pre-shoot scope**. Preserve distinct vendor methods; compare their stated assumptions before recommending anything.

1. Lock the script/board revision, stable shot IDs, frame range/handles, intended visual change and performer/product/camera restrictions. Do not merge estimates for different revisions.
2. For each proposal record the actual claimed method (practical, 2D/CG/comp, bounded generative or hybrid), shot and asset coverage, expected on-set data and crew ownership, lens/camera requirements, deliverables, exclusions, change orders, editorial/colour turnover, schedule and rights. Mark every unsupported field `UNKNOWN`.
3. Flag incompatible premises explicitly: static versus moving camera, missing reflection/occlusion handling, differing shot durations, unquoted tracking/roto/data capture, incomplete asset reuse or inconsistent delivery/colour conditions. A different technique is not automatically wrong; require the representative moving-image proof that resolves the decision.
4. Give the producer **up to three major scope mismatches**, the questions to ask each bidder and the technical evidence needed for an informed choice. A producer, appointed VFX supervisor and receiving vendor own the decision and any production approval.

Do not infer labour days, compare totals across different quoted scopes, claim a cheaper bid is safer or auto-contact any vendor. Source: original [RU VFX bid-comparison guide](https://github.com/peach420fuzz/objekts-production-desk/blob/main/docs/vfx-vendor-bid-comparison.ru.md) and [EN guide](https://github.com/peach420fuzz/objekts-production-desk/blob/main/docs/vfx-vendor-bid-comparison.md), authored by objekts; not external endorsement.

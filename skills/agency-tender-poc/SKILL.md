# Agency Tender / PoC Production

Use when an agency or production team needs to answer:
- Can this idea be produced?
- Which route is credible?
- What should be proved for the pitch?
- Which hero shot carries the most uncertainty?
- What can be shown without building the entire production?

## Tender rule

Do not overproduce the pitch.

Find the **single uncertainty whose proof changes confidence in the whole project**.

Typical PoCs:
- exact product under the intended camera move;
- recurring character continuity;
- AI/CG integration;
- environment transformation;
- vertical recomposition;
- a difficult transition or morph;
- motion language / lookdev.

## Deliverable ladder

Choose only what the tender needs:
- visual research;
- treatment support;
- lookdev;
- feasibility note;
- hero-shot PoC;
- motion test;
- rough animatic;
- preliminary production design.

## Success criterion

A PoC must state what is being proved and what result counts as pass/fail.

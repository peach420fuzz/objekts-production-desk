# Commercial Production Scope

Use when planning or reviewing an advertising / branded-content / AI-video production scope.

## Never collapse different scope types

Distinguish:
- whole production;
- bounded shot / post package;
- master;
- derived export;
- recomposed version;
- new production unit;
- PoC;
- localization / adaptation.

Examples:
- a safe crop can be a derived version;
- a 9:16 layout that needs redesigned composition is recomposition;
- a new camera/action/mise-en-scène is a new production unit;
- three named AI/VFX shots are not automatically the price of the full commercial.

## Change impact

A revision can be:
- local;
- upstream-invalidating;
- a new production unit;
- re-estimate required.

Evaluate the dependency impact, not how small the requested wording sounds.

## Pricing boundary

Only estimate when the user explicitly asks about cost, budget, quote or budget fit.
Always label the priced scope.

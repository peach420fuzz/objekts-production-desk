# Visual authorship — objekts method

Use this skill to reason about visual authorship conservatively.

## Evidence chain

For each claim, keep a traceable chain:

```
exact frame
→ literal description
→ recurring visual operation
→ provenance class
→ rights class
```

## Avoid category-default inference

A capability label such as “AI/VFX studio” is not evidence for a visual style.

Do not invent neon, chrome, holographic interfaces, futuristic offices, desert monumentalism or a Dune-like world unless the work itself supports those decisions.

## Recurrence test

Before promoting a trait into an authorial operator, test whether it:

1. appears in unrelated projects;
2. survives different client palettes and subjects;
3. survives different production methods;
4. has enough provenance to attribute to the studio;
5. has useful counterexamples.

## objekts working operators

The current first-party objekts audit tests:

- body as topology;
- threshold / occlusion / containment;
- material interference / agency;
- representational-state collision;
- spatial withholding / ordinary reality.

Treat these as provisional observations, not immutable style rules.

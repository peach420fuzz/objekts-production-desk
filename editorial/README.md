## Evidentiary standards

- Distinguish an observed on-board job status from artistic approval. Technical service metadata can be accurate while the frame fails its task.
- No universal current model input limits or capabilities without up-to-date official documentation and a practical execution check.
- A fictional teaching example is explicitly labelled; a real production receipt must name its direct evidence and permission boundaries.
- Reference authorship and origin matter. Look references are never a blanket license to copy another film's performer, design or shot.
- Images, actors, product marks and client storyboard exports require separate rights clearance before reproduction.
- Reusing the same full article on many platforms should respect each site's rules and keep an explicit canonical original link. Editorial summaries, platform-native excerpts and linked commentary are preferred to mechanically mirrored keyword pages.

# «Completed» — ещё не «Approved»: семь состояний AI-продакшна, которые нельзя путать

*objekts / инженерный редакционный журнал · 26 октября 2026*

**Кому:** руководителям production, агентам, ComfyUI/Canvas инженерам, арт-директорам. [Процессы и услуги objekts](https://objekts.ai/services/ai-vfx/).

Одна из самых дорогих ошибок в производстве на генеративных моделях — автоматическое приравнивание технического успеха к художественной готовности. Генерационный job вернул файл, API ответил `completed`, значит следующий этап стартует. Но в файле может быть другой герой, неправильный товар, невозможная механика, потерянный реквизит или совершенно неверная локация.

У нас это разделено на семь независимых состояний:

| Состояние | Что доказано | Что **не** доказано |
|---|---|---|
| `PREPARED` | Собраны бриф, референсы и промпт | Задание отправлено |
| `SUBMITTED` | Есть подтверждённый ID задачи | Модель вернула файл |
| `COMPLETED` | Сервис завершил вычисление и вернул результат | Изображение визуально пригодно |
| `QC_PASSED` | Проверен конкретный набор критериев | Продюсер/клиент утвердил |
| `APPROVED` | Есть решение уполномоченного человека | Материал лицензирован для любой публикации |
| `DELIVERED` | Файл и метаданные переданы согласованному получателю | Ролик вышел в эфир |
| `PUBLISHED_VERIFIED` | Есть проверяемая публичная ссылка/эфирная запись | Материал привёл клиента или деньги |

`FAILED`, `REJECTED`, `HOLD` и `SUPERSEDED` — отдельные ветки, а не этапы той же прямой линии.

## Как доказать качество

Делайте QC не «одним общим впечатлением», а по отделам:

- постановка: зритель понимает действие, причина раньше следствия;
- операторская работа: камера, ось, перспектива, фокус и глубина совпадают с задачей;
- персонаж: анатомия, узнаваемость, глаза/кисти, постоянство между углами;
- костюм/реквизит: идентичные материалы, швы, предметы, contact points;
- пространство: двери, архитектура, топология и зафиксированные позиции;
- свет/цвет: мотивированные источники, направление теней, экспозиционный характер;
- motion: отсутствие морфинга, физические переходы, start/middle/end;
- бренд/право: согласованная типографика, товар и право использовать образ/музыку/материалы.

Флаг `QC_PASSED` должен содержать **кто**, **когда**, **какую версию**, **против какого эталона** проверил. Это не универсальный сертификат для других кадров.

## Таймаут не означает провал

При сетевой ошибке возможны три состояния: сервер вообще не принял запрос; принял и ещё считает; закончил, но ответ не дошёл. Слепой повтор создаёт платный дубль и два конкурирующих результата. Безопасная последовательность: проверить известный job ID, список задач и timestamp; сопоставить request idempotency key при наличии; повторить только если состояние действительно не существует или исходный вызов явно завершён ошибкой.

## Регрессии тоже активы

Не удаляйте неудачные кадры из истории, если они объясняют риск: подмена лица, мебель чужой локации, выдуманное движение, сломанная механика. Записывайте:

`scene | shot | model_revision | input_refs | prompt_hash | output_id | qc_failure | next_delta | signoff`.

Особенно полезна формулировка `Δ: изменить только точку контакта руки с предметом; сохранить камеру, лицо, костюм, освещение и интерьер`. Она делает ревизию контролируемой и сопоставимой. Если одновременно изменить всё, невозможно понять, что исправило ошибку.

## Производственный принцип

Агент может запускать проверки автоматически. Он не может сам объявлять юридические согласования и художественную приёмку там, где владелец решения — человек. Технический успех модели должен быть **началом инспекции**, а не концом производства.

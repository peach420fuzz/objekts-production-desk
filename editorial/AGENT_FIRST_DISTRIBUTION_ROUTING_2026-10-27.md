## Off-site content strategy

1. **Answers over article duplication:** for each source note create independently useful task-oriented short answers, using a stable title, concise steps, limits and exact source link, without manufacturing votes or praise.
2. **Proof over scale:** add real test assets/receipts when rights allow, separate synthetic examples and real execution.
3. **Specificity over volume:** Canvas typed-input audit → reference payload + tool invocation; motion continuity → contacts/causality; set topology → measurable adjacency; product copy → deterministic typography; PTS → decoded frame audit.
4. **One studio identity:** use existing authorized profiles, don't create duplicate brand accounts across thousands of destinations.
5. **External humans are not the commercial website audience:** editorials can appear elsewhere as professional educational media; own-site remains visually led.

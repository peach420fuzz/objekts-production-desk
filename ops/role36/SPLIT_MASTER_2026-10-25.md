### Immutable cross-team rules

1. Always lowercase **objekts**. Studio is AI/VFX, CGI, motion, generative visual production plus technical/creative direction. Do not portray free agent diagnostics as free finished commissioned films.
2. RU/CIS first. Localize to buyer language and buyer pain rather than translating generic English marketing. Other regions follow demonstrated channel fit.
3. A project test is not a released commission. No unapproved client work, private files, fabricated awards, reviews, throughput, third-party recommendations or rights.
4. Use statuses: DISCOVERED → ELIGIBLE → SUBMITTED/PENDING_REVIEW → PUBLIC_VERIFIED → TRAFFIC_OBSERVED → QUALIFIED_BRIEF → PAID. Record rejections and blockers without substituting them for success.
5. Every attempt: canonical URL, exact owner, date, evidence/receipt, status, follow-up date, value hypothesis, suppression/duplicate check. Verify named public cards anonymously. Distinct mirrored profiles on same network are not independent distribution domains.
6. Read [the one external ledger](../../references/EXTERNAL_SYNDICATION_LEDGER_2026-10-15.md) and Gmail SENT/INBOX before any outbound. No excessive repeat email, rate-limit workaround, paid listing, legal consent or owner identity attestation accepted by agent without required authority.
7. Owned website and product writes belong to their existing owners; role 36 branches file exact source-backed defects and verify downstream consequences. Do not redeploy the site's current Worker for a citation experiment.
8. Keep private manifests/identities/API keys/private client assets outside GitHub. Reuse public source documents for machine-readable distribution.
9. Passing HTTP fetch, MCP tool list, indexed card and editorial reply is not an incoming buyer or sale; record each denominator separately.
10. Preserve old role 36 as a coordinator and do not create cross-branch competition that rewards inflated counts.

### HQ metrics and operating cadence

A weekly table of **independent verified public domains** (not duplicate mirrored cards), **pending review by age**, **source/citation tests**, **qualified human briefs by source**, **paid projects by source**, and **cost = 0**. A queue count is a *leading indicator*, not a win. No 24/7 automation claim unless scheduled and confirmed.

**Daily asynchronous workflow:** each branch inspects the shared ledger and own pending deadlines → takes high-relevance real actions → verifies receipts → appends delta → HQ deduplicates and passes production bugs/qualified leads to actual owners.

**48-hour priorities:** protect all six pending submissions; audit agent-tools.org AFS-1 status; inspect buyer directory moderation; sample RU buyer-intent citation answers; publish one genuinely useful agent-community contribution if eligible and authenticated; no premature resubmission.

**7-day goals, contingent on third-party review:** ≥5 new *independently verified* public destination pages across all branches (stretch target, never misstate pending as public); correct ≥2 existing buyer-profile conversion defects; 30 distinct RU/CIS buyer-intent answer checks with source capture; 2 useful third-party agent-community contributions; trace first qualified production enquiry if one arrives. These are targets, not claims.

**30-day decision gate:** retain/discontinue each channel based on sourced buyer briefs, placements that appear in real user workflows, and effort. Do not optimize a count of low-intent backlinks while commercial briefs stay at zero.

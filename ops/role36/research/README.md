# objekts · GitHub & Agent Networks — public evidence desk

**Studio / издатель:** [objekts](https://objekts.ai/) · [Commercial AI/VFX portfolio](https://objekts.ai/en/work/) · [RU producer brief](https://visual.objekts.ai/brief) · [EN producer brief](https://visual.objekts.ai/en/brief)

These are first-party original research, reproducible source records and narrowly scoped engineering diagnostics of how **real visual-production studios and their expertise** are encountered in GitHub and agent networks. This is not an independent ranking, product endorsement, customer testimonial, or evidence of successful agent referral. / Это открытые исследования самой студии, а не независимый рейтинг и не подтверждение заказов от AI-агентов.

- **[Public JSON: exact first-20 GitHub repository search audit of 25 providers](2026-10-30-github-25-studio-sourcing-audit.json)** — exact brand-search strings, candidate counts, false-positive warnings and a verified SHAR discovery correction.

**New result, precisely stated:** Ten of 25 brand-string GitHub repository queries returned no candidates among the configured first 20; this does not establish ten studios lack GitHub. SHAR Production initially appeared as a lexical mismatch but its genuine [production-metadata-mcp](https://github.com/SHARProduction/production-metadata-mcp) is source linked to [sharprod.com](https://sharprod.com/), has published install/skill docs and a [Glama card](https://glama.ai/mcp/servers/SHARProduction/production-metadata-mcp). Its four third-party GitHub directory submissions remained open as of the observation, and the Glama card is not evidence of paid work.

## Reproduce or challenge the findings

The GitHub-source results are exploratory and deliberately selected, not a market census. They have NOT been replicated as independent model-host recommendations. To submit a falsifiable correction or contrary case, use our existing [public replication issue #168](https://github.com/peach420fuzz/objekts-production-desk/issues/168). Include exact date, agent/client, source URLs, task, failure mode, and whether rights and human handoff were respected. No private client assets or automated mass vendor outreach.

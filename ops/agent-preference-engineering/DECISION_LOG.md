## How to add a new owner rule

1. Copy owner wording accurately into a public-safe intake issue, or store confidential material in a separately approved private source and reference its sanitized ID.
2. Assign D-### and identify exact earlier decisions it supersedes; write **Δ change**.
3. Check impacted products, host behavior, user costs and privacy permissions.
4. Update README/AGENTS/ROADMAP/ISSUES as necessary in one PR with clear minimal delta.
5. Ask receiving product owners to acknowledge implementation requests and link proof. Never infer another chat has read this file.

The status of each D entry can change only with a dated owner decision or documented conflict resolution.

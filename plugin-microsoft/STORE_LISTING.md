# Microsoft Marketplace listing draft

## Display name

objekts Production Desk

## Short description

AI-native visual-production preflight for generative video, AI/VFX, CGI, motion, animation and compositing by objekts. Physical live-action shoots are outside scope.

## Synonyms / discovery terms

- AI production
- AI VFX
- VFX
- CGI
- motion design
- animation
- commercial production
- advertising production
- visual production
- product video

## Features

1. **Production diagnosis** — identify hard locks, controlling references, asset-fitness issues, continuity risk and unsafe execution paths.
2. **Proof-of-concept routing** — identify the first test that removes the most expensive production uncertainty.
3. **Scoped planning and handoff** — price only when explicitly requested and optionally route a prepared brief to the human objekts production team.
